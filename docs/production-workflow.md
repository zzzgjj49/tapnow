## 操作行为

| 控件 | 实际行为 | 验证方式 |
| --- | --- | --- |
| 模型、方式、比例、清晰度、时长、声音 | 更新节点参数、自动保存、进入生成请求 | 浏览器点击与 HTTP 断言 |
| 数量 | 1、2、4 个独立请求，每个带唯一请求标识 | 浏览器与测试网关 |
| 多镜头 | Kling 节点开关，随请求传递 `multiShot` | API 参数验证；生成效果待厂商接入 |
| 素材库 | 自动连接节点并加入选中引用，支持取消选择 | 浏览器与 HTTP |
| + / 上传参考素材 | 按模式上传图片或图片/视频/音频 | HTTP 测试 |
| 首尾帧 | 按媒体添加顺序分配首帧/尾帧，至多两张图片 | 服务端校验 |
| 视频编辑 | 要求参考视频，提交 `source-video` 角色及编辑提示词 | HTTP 测试 |
| 麦克风 | 浏览器语音识别写入提示词，可停止 | 模拟识别回调；真实权限和识别服务待现场验证 |
| 生成 | 校验输入、提交网关、保存任务编号、防止重复提交 | 本地测试网关 |
| 刷新进度 | 手动查询；页面同时自动轮询 | 浏览器与 HTTP |
| 失败重试 | 保留错误，可重新提交新一批任务 | HTTP 测试 |
| 结果切换 | 更新预览、保存选中结果，并供下游引用 | 浏览器与 HTTP |
| 下载 | 服务端流式下载选中结果，避免浏览器跨域限制 | 本地测试媒体字节验证 |
| 右键拖动 | 空白处及节点上均平移，不改变节点坐标 | 浏览器实际鼠标事件 |

积分示例：Fast 720p、15 秒、1 个结果约 300；2.0 4K、15 秒约 1815；2.5 720p、30 秒约 1200。仅推算截图展示费率，使用 `≈` 区分估算。未知组合显示“生成”，没有余额或真实扣款系统。
